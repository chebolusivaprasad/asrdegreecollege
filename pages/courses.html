BCA

A flagship, software-focused undergraduate degree designed to make students fluent in modern coding languages, full-stack web engineering, and enterprise database systems.

Core Subjects & Lab Tech:
Python, Core & Advanced Java, Web Technologies (HTML/CSS/JS/React), DBMS & SQL, Computer Networks, Operating Systems.
