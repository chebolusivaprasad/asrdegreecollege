# ASR Degree College Website

A modern, high-performance, and client-ready website for **ASR Degree College, Atmakur** (Affiliated to Vikrama Simhapuri University).

## 🚀 Pure HTML, CSS & Vanilla JavaScript
This project has been completely rebuilt using **100% pure static web standards**:
- **Zero build steps required** (no Node.js, Vite, or npm required to host or view).
- Works directly on any shared hosting (cPanel, Plesk, Hostinger, GoDaddy, Namecheap, Bluehost, etc.).
- Works directly on Apache, Nginx, GitHub Pages, Netlify, or Vercel.
- Works offline directly in the browser by opening `index.html`.

## 🌐 How to Upload to Hosting (cPanel / Shared Hosting)
1. Open your hosting control panel (e.g. cPanel File Manager).
2. Navigate to your `public_html/` (or domain root) folder.
3. Upload all files and folders (`index.html`, `asr-logo.svg`, `css/`, `js/`, and `pages/`).
4. That's it! Your website is live immediately with high-speed performance and zero server overhead.
